# 源码检查与功能交付清单

实际参考根目录：本地参考工程 Adaptive-rag-main。README.md、pyproject.toml、app、tests、eval、knowledge 均位于该根目录。教程根目录为旁边的 all-in-rag-main，按索引构建、检索进阶、生成评估和高级应用联系本项目。

| 能力 | 检查时已有实现 | 本次处理 |
|---|---|---|
| 加载/清洗/分块/元数据 | Markdown 与可选 Unstructured、去重、PII 清理 | 相对路径 ID；人类标题、政策版本和相对来源；每份政策标注演示 |
| 中文向量/BM25/RRF | 本地 BGE、jieba+BM25、RRF；Hash 后备 | 标题/小节参与索引；Hash 中文分词；本地向量快照 |
| Cross-Encoder | sentence-transformers CrossEncoder，加载失败词面后备 | 禁止默认下载/远程代码；真实下载与推理；界面显示实际 backend |
| 意图与五路路由 | LLM+规则覆盖层+复杂度 | 政策与交易区分；ORD10001 等五位 ID 正确识别 |
| Self-RAG | 改写、累积、有限循环 | 执行多条查询；保留原问题；裁判异常不判充分；逐轮轨迹 |
| 引用/忠实度 | 回答 JSON 引用、裁判与一次自纠错 | 校验所选引用；修正后重新匹配；不可信则拒答；裁判故障失败关闭 |
| 模拟工具 | 订单、物流、退货/退款/取消，权限与幂等 | 持久化待确认动作，绑定归属与参数；确认重放；并发确认测试 |
| 记忆 | 摘要、滑动窗口、三级压缩 | 加载保存摘要、必要追问消歧、工具 payload 计预算 |
| 可靠性 | JSON 日志、HTTP 超时/重试、指标 | 请求独立计数与实际 HTTP 次数；检索失败状态；便宜 readiness |
| 评估/测试 | 历史集、metrics、154 项测试 | 原测试保留；16 项新增；26 题 dev/test 分离；逐题结果与完整证据 |
| 浏览器界面 | 无 | **本次新增**同源 HTML/CSS/JS，真实后端、引用、轨迹、确认与模式 |
| MCP/外部存储 | 本地/HTTP MCP，PostgreSQL、Redis、Qdrant 可选 | 保留合理入口，不连接外部业务；基础启动不依赖它们 |

检查时确认的问题由代码证据得出，未把用户给出的所有检查方向当成已存在缺陷。历史 README 的性能数字没有作为本项目成绩继承。
