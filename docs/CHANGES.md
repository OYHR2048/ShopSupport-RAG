# 改进记录

| 修改 | 原因 | 验证与结果 |
|---|---|---|
| 保留 app/tests/knowledge/eval 主体 | 先复用成熟实现，避免全部重写 | 154 项原测试全部保留并通过 |
| 稳定文档 ID 与相对来源 | 绝对路径在换机器后变化 | 跨不同根目录 ID 相同、不同子目录仍区分的测试通过 |
| 标题索引与中文特征哈希 | 浏览器发现简单退货问答混入无关片段；关键规则可能位于小节标题 | 增强验收断言，要求真实签收时限正文；通过，不放宽测试 |
| 政策/交易路由和有界订单计划 | 原关键词“退货/物流”易把政策咨询送工具；演示订单为五位数字 | 简单政策 SINGLE、复合问题 MULTI、订单 AGENT 测试通过 |
| 逐轮改写/证据/停止轨迹 | 原循环只执行首条改写，异常把有片段视为充分 | 多查询执行、累积去重、最大轮数与裁判故障测试通过 |
| 忠实度故障关闭与引用重建 | 原裁判异常返回 supported=true；修正后引用未同步 | 裁判异常拒绝可信判定；修正仍不可信终止；引用 API 与原文一致 |
| 服务端待确认动作表 | 非空 confirm_action_id 不足以授权操作 | 伪造、跨会话、改变消息参数、重复/并发确认测试通过 |
| 摘要加载与追问消歧 | 保存摘要但初始化未使用；后续短问缺实体 | 订单物流追问、政策追问、会话所有权测试通过 |
| ContextVar 统计 | 多个模型节点的 usage 不能只统计生成节点 | 并发请求计数隔离、重复确认本次计数为零 |
| 同源浏览器与演示 provider | 原 FakeLLM 默认 JSON 无法形成可理解演示 | UI 接真实 POST，显示实际 backend；演示回答明确为原文摘录 |
| 新评估集与比较程序 | 历史结果未包含原始逐题数据，部分标注粗糙 | 8 dev/18 test，标注原文自动校对；真实模型和占位结果分开保存 |

模型下载第一次网络中断，保留部分文件并通过续传完成。记录具体模型 revision；加载只允许本地文件与 safetensors，不启用 trust_remote_code。

质量检查：170 项测试通过；Ruff、mypy、pip check 通过。LangGraph 依赖有一条关于未来序列化默认值的弃用提醒，未通过过滤它来伪造零警告。

详细性能以 reports/ 和 EVALUATION.md 为准。没有观察到提升的模块如实记录。真实生成、真实语义充分性/忠实度裁判尚未验证，本轮未使用付费 API。
