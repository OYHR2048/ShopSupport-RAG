# 本次评估集口径

reviewed.jsonl 是本次根据真实政策原文重新建立的 26 题：8 题 dev 用于调参，18 题 test 用于最终比较。每题保存原文位置与片段，compare.py 会核对标注文本确实存在。

标注由开发时源码/原文检查建立，用户可以人工复核；没有声称已由独立标注人员审核。原仓库 dataset 与 MEASURED.md 保留为来源材料，其历史数字不是本项目结果。

相关文档集合允许替代依据，文档 Recall@3 与“所有标注原文均被检索到”分开报告。无答案题不计相关文档 Recall，单独检验充分性决策。向量/混合/重排自身只排序，不具有拒答决策，decision_correct 为空。

固定路径和自适应路径使用同一召回、重排与裁判。不开 allow-paid 时，裁判只做演示词面覆盖检查；即使加载真实 BGE，也不能声称真实生成和语义 Self-RAG 验证通过。结果不预设每个模块有改善。
